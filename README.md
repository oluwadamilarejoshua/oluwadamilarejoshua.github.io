# oluwadamilarejoshua.github.io

Personal academic website of Joshua Ogundairo, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Where to edit

- Homepage and news: `_pages/about.md`
- Papers: `_publications/` (one Markdown file per paper; `category: working` or `manuscripts`; optional `status` and `authors` fields)
- Presentations: `_talks/` (use `when:` for the displayed date)
- Teaching: `_teaching/`
- CV page: `_pages/cv.md`; the PDF lives in `files/Joshua_Ogundairo_CV.pdf`
- Site settings and sidebar links: `_config.yml`; menu: `_data/navigation.yml`
